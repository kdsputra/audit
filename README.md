# Audit Tools

Audit Tools is a static GitHub Pages application containing multiple audit utilities.

## QuizArena

- `quiz-arena/` contains the deployed static QuizArena sub-app used by `index.html`.
- `quiz-arena-source/` contains the original QuizArena source project copied from `kdsputra/quiz-arena`.

The source folder is kept in this repository so QuizArena can be maintained from `audit` even if the standalone `quiz-arena` repository is removed later.
