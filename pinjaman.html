Panduan Lengkap Penggunaan

Aplikasi ini menghitung jadwal amortisasi pinjaman dengan metode Suku Bunga Efektif (EIR). Biaya provisi yang dibayar di muka akan diamortisasi sepanjang periode pinjaman sehingga menghasilkan tarif efektif yang berbeda dengan tarif nominal.

1. Logika Perhitungan

  • Total Bayar (PMT): Cicilan bulanan tetap yang dihitung dengan rumus anuitas atas nominal pokok dan suku bunga nominal.
  • Bayar Bunga: Sisa Saldo Nominal × (suku bunga tahunan / 12).
  • Bayar Pokok: Total Bayar − Bayar Bunga.
  • Bunga EIR: Sisa Saldo EIR sebelumnya × tarif EIR bulanan.
  • Amortisasi EIR: Bunga EIR − Bayar Bunga (ditampilkan negatif sebagai selisih amortisasi provisi).
  • EIR: Tarif dicari iteratif sehingga Sisa Saldo EIR berakhir tepat di nol pada periode terakhir.

2. Pengisian Excel

Header pada baris pertama file Excel harus berisi kolom-kolom berikut (mendukung penamaan EN/ID):

  • name (nama): Nama atau referensi pinjaman.
  • nominal (pokok): Nilai pokok pinjaman dalam angka penuh tanpa titik/koma (contoh: 10000000000).
  • start_date (tglmulai): Tanggal pencairan/mulai pinjaman (DD/MM/YYYY).
  • end_date (tgljatuhtempo): Tanggal jatuh tempo (DD/MM/YYYY).
  • interest (bunga, rate): Suku bunga tahunan (0.10 atau 10 atau 10%).
  • provision (provisi, biayaprovisi): Biaya provisi di muka (boleh 0).
Tips: Klik tombol "Unduh Template Excel" untuk mendapatkan format yang sudah siap diisi.

3. Langkah Penggunaan

  • Input data melalui form manual (klik "Tambah ke Daftar") atau impor file Excel bulk.
  • Tanggal cut-off opsional, untuk valuasi nilai buku per tanggal pelaporan.
  • Proses Hitung akan menghasilkan dashboard statistik, tabel ringkasan, dan jadwal detail per pinjaman.
  • Unduh Excel untuk menyimpan kertas kerja lengkap (summary + detail tiap pinjaman).

Catatan: Aplikasi ini berjalan sepenuhnya di browser. Data pinjaman tidak diunggah ke server manapun.
