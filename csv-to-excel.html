Panduan penggunaan

Konversi CSV apa pun — termasuk berukuran puluhan/ratusan GB — jadi file Excel, langsung di browser.
1
Pilih file CSV
Tarik file ke kotak unggah atau klik untuk memilih. File tetap di komputer Anda — tidak ada yang diunggah ke server.
2
Periksa format
Delimiter, encoding, dan header dideteksi otomatis. Ubah manual bila perlu, lalu cek tabel pratinjau.
3
Pilih folder hasil
Tempat file Excel ditulis. Di Chrome/Edge ditulis langsung ke folder; di Safari/Firefox diunduh otomatis.
4
Mulai konversi
Data melebihi 1.048.576 baris otomatis dipecah jadi part001.xlsx, part002, dst.
Tips penting
  • File raksasa aman. File dibaca per potongan secara streaming, jadi pemakaian memori tetap kecil (±15–20 MB) berapa pun ukuran CSV.
  • Aman untuk audit. Secara default angka disimpan sebagai teks, sehingga kode akun, NIK, dan angka berawalan 0 tidak rusak.
  • Untuk CSV puluhan GB & banyak file, gunakan Chrome atau Edge (Mac/Windows) agar bisa menulis langsung ke folder.
