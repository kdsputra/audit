Panduan Lengkap Penggunaan

Aplikasi ini menghitung jadwal amortisasi Liabilitas Sewa dan Right-of-Use (ROU) Asset sesuai PSAK 73 / IFRS 16 secara massal. Berikut panduan langkah demi langkah.

1. Struktur File Excel

File Excel harus memiliki dua sheet:

Sheet "lease" (Master Kontrak):

  • lease_id: Kode unik kontrak lease (contoh: lease001).
  • nominal: Total nilai kontrak lease (Present Value akan dihitung otomatis).
  • upfront: Pembayaran di muka saat inisiasi (boleh kosong/0).
  • payment_option: Skema pembayaran. Opsi: custom (gunakan jadwal sheet payment), monthly, quarterly, annually.
  • start_date: Tanggal mulai kontrak (DD/MM/YYYY).
  • end_date: Tanggal berakhir kontrak (DD/MM/YYYY).
  • interest: Tingkat bunga implisit/incremental borrowing rate (desimal, contoh: 0.035 untuk 3.5%).

Sheet "payment" (Jadwal Pembayaran):

  • lease_id: Kode kontrak yang sama dengan sheet lease.
  • periode: Tanggal pembayaran (DD/MM/YYYY).
  • payment: Jumlah pembayaran pada periode tersebut.
Tips: Klik tombol "Unduh Template Excel" untuk mendapatkan format standar yang sudah siap diisi.

2. Output yang Dihasilkan

Untuk setiap kontrak lease, aplikasi menghasilkan jadwal bulanan dengan kolom:

  • ll_begin / ll_end: Saldo Liabilitas Lease awal dan akhir bulan.
  • ll_payment: Pembayaran yang mengurangi liabilitas (termasuk bunga).
  • ll_exp: Beban bunga (interest expense) yang menambah liabilitas.
  • rou_begin / rou_end: Saldo ROU Asset awal dan akhir bulan.
  • rou_exp: Beban penyusutan ROU Asset (garis lurus).
  • exp_com: Total beban komersial (ll_exp + rou_exp).
  • exp_fiscal: Beban fiskal = total pembayaran lease (cash basis).
  • tax_correction: Koreksi fiskal = exp_fiscal - exp_com.
  • dta / dtl: Deferred Tax Asset / Liability berdasarkan tarif pajak.

3. Langkah Penggunaan

  • Siapkan Data Excel dengan dua sheet di atas.
  • Unggah File: Drag & drop atau klik kotak upload.
  • Set Cut-off & Tarif Pajak pada Langkah 2.
  • Klik "Proses Hitung Amortisasi Lease".
  • Review Dashboard & Tabel dan pilih lease pada dropdown untuk melihat jadwal detail.
  • Klik "Unduh Excel" untuk menyimpan kertas kerja.
